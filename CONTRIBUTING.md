# Contributing to Windpeek

Contributions are welcome. Bug reports, design proposals, documentation fixes,
and focused pull requests all help the project.

## Before opening a pull request

1. Open or reference an issue for changes that affect product behavior or the
   interface, so the direction can be discussed before substantial work begins.
2. Keep each pull request focused on one change.
3. Add or update tests for behavior changes and run the relevant checks locally.
4. Explain what changed, why it changed, and include screenshots for visual work.
5. Only submit work that you have the right to contribute. Identify copied or
   adapted material and preserve its required notices.
